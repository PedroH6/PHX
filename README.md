# PHX — Outcome Growth OS

Front-end responsivo do PHX, uma plataforma de campanhas, CRM, agenda e IA orientada a resultados.

## Stack

- React
- React Router DOM
- Tailwind CSS
- Vite
- Lucide React

## Rotas

- `/dashboard` — visão geral e métricas
- `/objetivos` — criação de outcomes/resultados
- `/campanhas` — campanhas e criação assistida por IA
- `/inbox` — conversas
- `/clientes` — CRM
- `/agenda` — agenda e disponibilidade
- `/ia` — agente de IA
- `/configuracoes` — workspace e integrações

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O layout compartilhado fica em `src/components/AppLayout.jsx`. Cada página está separada em `src/pages/` e as rotas ficam em `src/App.jsx`.
