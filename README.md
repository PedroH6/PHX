# PHX — Outcome Growth OS

Front-end responsivo do PHX, uma plataforma de campanhas, CRM, agenda e automações orientada a resultados.

## Stack

- React
- React Router DOM
- Tailwind CSS
- Vite
- Lucide React

## Rotas

- `/dashboard` — visão geral e métricas
- `/objetivos` — criação e acompanhamento de objetivos
- `/campanhas` — campanhas
- `/inbox` — conversas
- `/clientes` — CRM
- `/agenda` — agenda e disponibilidade
- `/configuracoes` — workspace e integrações

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O layout compartilhado fica em `src/components/AppLayout.jsx`. Cada página está em `src/pages/` e as rotas em `src/App.jsx`.
